BlueSquare

Privacy notice
Unlike similar tools that run private, server-side scripts, BlueSquare runs entirely in your browser. This website is not backed by a server that collects or stores your Bluesky data. The code is publicly hosted on GitHub and executed locally in your browser when you use the tool. Your Bluesky account data is used only to generate your square and is not sent to or stored by anyone. There is no user tracking or analytics built into the tool. Since it's a client-side only tool, the more you are active on Bluesky, the longer the tool will run before the result. Results are based on the past 7 days. I can't build à 1 month tool without hosting it on an actual paid server.
